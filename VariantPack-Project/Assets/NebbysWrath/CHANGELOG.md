# Changelogs

## 3.1.1 - HD Sprites

* Added a "Risk of Rain Returns" version of the Amalgamated Wisp sprite that appears on loading screens (Thanks TangoKnight!)
    * This is configurable, when the config is being bound and you have Kina's "LoadingSpriteAdditions" mod installed, they'll be turned on by default.
* Most of the spawn conditions from the mod now use the simpler ``ExpansionRequirementCondition`` instead of ``BasicSpawnCondition``
* Fixed an issue where the Ancient Magma Worm and the Ancient Overloading Worm would never spawn naturally.
* Added the following enemies to The Original 30's spectral jellyfish pool:
    * Alpha Construct
    * Blind Pest
    * Blind Vermin
    * Gip
    * Void Barnacle
    * Child
    * Solus Scorcher

## 3.0.0 - Rewrite

* Rewritten to use VarianceAPI 3.0.0
* Changed some of the spawn rates overall
* Added the following variants:
    * Ancient Worm
    * Bloated Pest
    * Cloaked Extractor
    * Deffective Slammer
    * Evil Buddy
    * Glitched Wing
    * Hatchling Worm
    * Invalidaint Mine
    * Kamikaze Reaver
    * Kleptomaniac Extractor
    * Malfunctioning Amalgamator
    * Meatballer Lemurian
    * Nullifying Mine
    * Oilspiller
    * Pinky
    * Proto Wing
    * Roller Pod
    * Scrapyard Hunter
    * Theta Construct
* Added Configurations for adding the following Variant Clones. These are true by default
    * Ally Variants. Creates Variant versions of the following bodies:
        * Lemurian (Artifact of Devotion)
        * Elder Lemurian (Artifact of Devotion)
        * Alpha Construct (Defense Nucleus)
        * Solus Probe (Empathy Cores)
        * Void Reaver (Newly Hatched Zoea)
    * Polymorph Lemurian. Creates variant versions of the Lemurian Polymorph from DLC4, using the existing Lemurian Variants
	* Artifact of Soul Wisps. Creates Variant versions of the Artifact of Soul wisps, using the existing Lesser Wisp variants
    * Alloy Worship Unit. Creates variant versions of the Alloy Worship Unit, using the existing Solus Control Unit variants
