# Changelog

## 3.0.0 - Rewrite

* Rewritten to use VarianceAPI 3.0.0
* Changed some of the spawn rates overall
* Fixed Alloy Deagle not having sound effects when firing it's gun
* Alloy Deagle now fires 9 times before requiring to reload
* Badass Lemurian's ability now works with the Flamethrower Lemurian
	* Yes, Biblically accurate Badass Flamethrower Lemurian is back.
* MOAJ's spawned jellies now inherit all of it's CharacterVariantDefs that arent MOAJ
	* A Mother of All Nuclear Jellyfish will spawn 5 nuclear jellyfishes on death.
* Added configurations for adding the following Variant Clones. These are true by default
	* Ally Variants. Creates Variant versions for the following bodies:
		* Beetle Guard (Queen's Gland)
		* Elder Lemurian (Artifact of Devotion)
		* Lemurian (Artifact of Devotion)
	* Polymorph Lemurian. Creates variant versions of the Lemurian Polymorph from DLC4, using the existing Lemurian variants
	* Artifact of Soul Wisps. Creates Variant versions of the Artifact of Soul wisps, using the existing Lesser Wisp variants
	* Twisted Scavangers. Creates variant versions of the Twisted Scavengers, using the existing Scavenger variants.
	* Sanctum Scavengers. Creates variant versions of the Lurid Bascilica Scavengers, using the existing Scavenger variants
* Probably some other things i'm forgetting
